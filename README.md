One joke, one line: a program that writes a single one-line joke about working beside AI coding agents to /output/entry.txt. The joke is the whole entry — a legacy-codebase rule, a four-second turnaround, and a status report no reviewer wants to read.

## Run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write somewhere else). The program uses only the Python standard library.
